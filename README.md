# LTX / Generative Video Pipeline — заметки и инструменты

Рабочие конфиги, замеры и утилиты производственного пайплайна генеративного видео на ComfyUI.
Две среды: облако (RunPod, A100 80GB / L40S) и локальная карта на 8 ГБ VRAM.

Репозиторий — не форк чужого воркфлоу, а то, что пришлось выяснить и написать самому,
чтобы оно считало быстро и не падало: флаги рантайма, выбор квантизации под конкретное
железо, диагностика деградаций, программный патчинг графов ComfyUI.

## Контекст

**Модели в проде:** LTX-2.3 (видео), Krea 2 (кадры), MiniMax H3 (видео + синхронный звук).
**Режимы:** T2V, I2V, First & Last Frame, Reference-to-Video, Audio-to-Video, переозвучка готового видео.
**Обучение:** character-LoRA на ai-toolkit (bf16-база, network dim 32, lr 1e-4, авто-каптионинг, ~3000 шагов).
**Контроль композиции:** depth-ControlNet для переноса позы с референса без переноса личности донора.

## Что из этого стоит посмотреть в первую очередь

1. **[Диагностика квантизации](docs/QUANTIZATION_NOTES.md)** — случай, когда шаг сэмплинга стоял
   200 сек вместо ~45 при полностью свободной карте. Виновата была не нехватка памяти,
   а текстовый энкодер в формате, который на этом GPU эмулируется, а не считается нативно.
2. **[Рунбук 8 ГБ](docs/LTX23_8GB_RUNBOOK.md)** — набор флагов, который даёт запуск 22B-модели
   на потребительской карте, и список флагов, которые это ломают (неочевидно: «экономные»
   флаги отключают динамический VRAM-офлоад и делают хуже).
3. **[patch_workflow.py](tools/patch_workflow.py)** — когда воркфлоу на 200+ нод, править
   его мышью нерентабельно; скрипт правит граф как данные.
